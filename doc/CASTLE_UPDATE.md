# 无限城成长与玩法调整

本轮保留一口气深入无限城的剧情规则：不新增暂停、探索快照或续关。装备配置、选择的流派和已结束探索的战报可以保存，但不能恢复某一层继续挑战。

## 成长与难度

- 保留旧存档的天赋 ID、20 级上限和传承门槛，不要求玩家重开。
- 快刀术每级伤害 +4%；低伤武器的小数增伤累计到后续命中，避免每次向下取整吞掉成长。
- 铁壁每级减伤 1.5%，上限 30%；风刃每级减少武器冷却 1.5%，上限 30%，同类武器共享冷却也应用加成。
- 硬体术每级增加 5 点生命上限时同步补充新增生命；入城先授予继承天赋，再恢复到新的上限。
- 探索者赐福按基础生命与天赋/深度生命加成的合计值计算 15%。
- Boss 战后固定给予两次天赋选择。补给与直接继续两条路径奖励一致。
- 围剿按实际战斗数量给予 3～5 次天赋选择；所有选择都在前一事件关闭后发放，不依赖猜测动画耗时。
- 节点权重按总和归一化，早期不会少生成选项，后期也能遇到柱与祭坛。
- 磨刀花费 30 木头，为下一整场战斗的命中增加 1 点伤害。
- 战内与整顿栏共用治疗计算，包括滋养、治疗传承和实际回复量累计；满血不扣药。

普通怪的攻击间隔不低于 1 秒。20 层后每层生命增加 6，伤害缓慢增加；精英保留额外血鬼术与倍率。

## 玩家操作

- 在无限城入口选择流派，再确认深入。战斗内不能切换流派。
- 在漫漫尘途保存“远征”或“无限城”的装备与补给目标；“补齐我的配置”补足缺额，缺货或空间不足会提示。
- 失败回营后阅读战报；入口可重新查看上一次已结束探索的报告。

## 验证

补充修复：首次战斗在尚未挂载的事件面板内绑定攻击/治疗快捷键；重复出现的事件重置关闭标记；水流派治疗计入战报；战报打开时不响应后台快捷键；旧滑动插件兼容当前 jQuery。

`npm run test:castle` 检查奖励完整性、事件栈归属、天赋/治疗/概率、流派、配置补齐与战报。

`npm run test:migrate` 检查已有旧存档迁移。

`npm run test:browser` 使用隔离的 Edge 测试档进行真实浏览器集成检查，不触碰玩家浏览器存档。需要 Node 22+；非默认安装位置可设置 `EDGE_PATH`。

浏览器回归覆盖配置保存和补齐、四种流派实战效果、原生键盘攻击与吃药、连续补给购买、Boss 双奖励，以及实际死亡回营后的战报和快捷键隔离。
