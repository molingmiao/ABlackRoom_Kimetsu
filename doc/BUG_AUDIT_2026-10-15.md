# 2026-10-15 游戏检查记录

检查范围包括存档迁移、前中后期主线、长线任务与彩蛋、无限城战斗和结算、制造和概率锻造、资源与回收、背包配置、键盘及桌面界面。这是一轮代码检查与回归验证，不表示所有可能的缺陷都已排除。

## 本轮修复

| 问题 | 修复后 |
| --- | --- |
| 普通制造先保存材料扣除，再保存产物 | 材料、成品及建筑状态一次提交，监听者只看到完成后的状态 |
| 图纸制造执行时未重新检查图纸、普通制作缺少完整前置复核 | 执行时复核地点、温度、建造者、工坊、图纸、数量与上限 |
| 失效图纸留下按钮或图纸行 | 同步撤下旧入口，过期调用不扣费 |
| 锻刀场使用全局常量但没有页面对象属性，公告按页面属性判定地点 | 正确导出同一个锻刀场对象，公告可用 |
| 检视窗口及定时事件缺少统一隔离 | 战斗／远征和已有弹窗期间拒绝叠开；随机事件与铁匠延期 |
| 成就窗口缺少键盘锁、原生关闭按钮及 Esc | 禁止背景快捷操作，Tab／Esc 可关闭并恢复焦点 |
| 无限城出发缺少野外已有的超重检查 | 摘要显示负重／容量，拒绝超重扣费并保留引路鸦 |

保持原有配方和核心数值，精油仍每批五瓶；没有增加暂停远征功能。畸形库存不由制造入口擅自修复或删除，验证失败时保留原状态。

## 验证入口

- `test:actions`：真实普通／图纸配方、单次保存完整状态、建筑、精油批量、材料不足、蓝图、上限、重入、畸形库存、定时事件隔离。
- `test:migrate`、`test:early`、`test:long-quests`、`test:expedition`：旧档及剧情、真实死亡和安全返程、一次性奖励、见闻和任务册。
- `test:castle`、`test:combat-supplies`：战斗、吸血、药物计时、结算、掉落返仓、技能突破、超重出发。
- `test:forge`、`test:economy`、`test:reserves`、`test:ux`、`test:camp`、`test:inventory-language`：配方、保底、回收、预算、生产保留、界面预览和汉化。
- `test:browser`：完整实际按钮流程；`GAME_BROWSER_FOCUS=action-integrity` 可聚焦本轮制作、弹窗和出发问题。
- `test:style-visibility`：多个桌面高度下原生鼠标／键盘滚动、锻刀、装备回收与技能卡片。
- `lint`、`build:web`、`test:web`：静态检查及发布资源完整性。

桌面回收测试中的一次失败来自预定成就奖励在取消窗口期间到账（太阳结晶增加），而非取消按钮扣费。已在测量基线前结算已达成成就，保留真实库存与余料的严格比较。
