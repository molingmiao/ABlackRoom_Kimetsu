# 呼吸流派与修炼：首轮扩展

本游戏的战斗效果是同人玩法设计，不是动画招式数值的照搬。名称与阶段参照[正版游戏游郭角色介绍](https://game.kimetsu.com/hinokami/character/paid_update.html)、[官方篇章顺序](https://game.kimetsu.com/hinokami2/mode/)与[官方神乐介绍](https://game.kimetsu.com/hinokami2/character/?chara=21)。游郭剧情参照 [ANIPLEX 游郭篇梗概](https://www.aniplex.co.jp/lineup/kimetsu_yukaku/story/)，玩家负责支援，不替代原作角色完成斩首。

月仅为本游戏的剑谱拟式：复现刀路和残切，不赋予鬼化、实体月牙或血鬼术，不宣称原作存在常规人类传承。

## 存档与战斗边界

- 保留六个 `infinityTalents` ID 与所有历史峰值，不增加突破需要刷满的项目；共同上限仍 20→25→30，之后 +5，20 级起按历史峰值 40% 继承。
- 六项共通修炼并非 14 份独立熟练度。换流派不清等级；当前流派只将其中对应的一项附加到专属效果，其他项目照常提供共通属性。奖励、祭坛和柱指导显示流派修炼名称与升级预览。
- 专属比例采用 `level / (level + 30)` 递减增长；高阶等级仍有收益，但不会变成百分百减伤或零冷却。
- 护盾、冥想、未命中不获得连击、不消耗蓄力或有限出刀次数；持续伤害不再次触发武器连击、剂量或吸血。
- 只有直接实受伤计入岩反击与霞守势；花凝神被所有实际伤害打断。恋增益只由熏肉、药剂、藤花油实际治疗触发，不由吸血、满血治疗触发。
- 本场连击、毒层、反击和计时器仅存在内存；结算、死亡、关闭场景时清除，不跨敌人。只保存所选流派与既有修炼进度，不增加活动探索存档、暂停或续关。
- 旧地图 O 原位改名为唯一游郭与 D/R 普通城镇，保留清图标记和视野；D/R 不增加探索者赐福的新门槛。

## 后续迭代方向（尚未实现）

继续结合实际游玩反馈核对各流派生存、弹药与伤害收益；再逐批扩展流派专属训练事件、招式选择与对应鬼的应对提示。日与月拟式不应成为水、虫、岩等流派的全面替代；每批新增内容均保留老存档并有实际战斗回归验证。
