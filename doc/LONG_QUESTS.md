# 长线任务与秘闻

本批为原创同人支线，不替代正篇战果，不增加主线、呼吸或探索者赐福的门槛。地图“剧情地点与见闻”中展开“长线任务与秘闻”可看下一站、待交付进度、开关和线索。普通地点先结束原有事件，再点任务册中的调查按钮；无名渡口和四角房间自动打开专属事件。

## 失名的引路人

从唯一的 **N 无名渡口**开始，通常距庄园约 9 格。每阶段需核对物证与证词再确认行动，可以同趟追查多阶段，也可分多趟安全返回交付。未交付进展死亡丢失；阶段 checkpoint 不是活动远征存档，没有暂停续关。

| 阶段 | 地点 | 主题 |
| --- | --- | --- |
| 1 | N 无名渡口 | 面对失名的鬼：封缚观察，或真正战斗后击杀 |
| 2 | Q 狭雾山旧道 | 绳结与旧账中的名字 |
| 3 | 任意 D 宿场旧街 | 被涂掉的账页与失踪药队 |
| 4 | J 藤之家 | 受害者的恐惧与相互矛盾的证词 |
| 5 | G 鼓屋外围 | 取回名单，路线改变是否需要战斗 |
| 6 | E 蝶屋 | 核对药箱和运输记录 |
| 7 | 任意 R 废弃市镇 | 寻找幸存者，不要求他们原谅 |
| 8 | K 锻刀村 | 断刃、仓号与最后的运输路线 |
| 9 | T 列车站外 | 保护最后一批失踪者，两路线战斗难度不同 |
| 10 | N 无名渡口 | 交还名单、锁定不同结局 |

选择在**安全交付后锁定**。放过不是解除看守或洗清罪责；击杀必须打赢，不能靠对话直接完成。

- **封缚查证**：口述线索参与后续调查，第 5 阶段避开伏击，第 9 阶段鬼生命 80、伤害 3；全线 1 场支线战斗。结局成就“留下答案的人”，一次性药剂 ×8、布料 ×40。
- **击杀追查**：失去口述来源，依靠物证与幸存者继续。第 1 阶段鬼生命 60、伤害 4，第 5、9 阶段鬼生命 130、伤害 5；全线 3 场支线战斗。结局成就“沉默之后的证词”，一次性鳞片 ×25、钢 ×15。
- 以上只计支线固定战斗；普通赶路仍有原有遭遇与补给消耗。成就互斥，同一存档不要求两个结局全得。中间阶段不反复发奖，结局重访不重复奖励。

## 三条彩蛋线

1. **四方灯火**：地图西北／东北／西南／东南四角的 1/2/3/4 房间，各读碑文并选择对应刻纹。选错不扣材料，可重读；可分多次远征开启并安全交付。四个开关全部交付后，下一次通过正常入口真实进入无限城，获得成就与太阳结晶 ×5。不是“账号从未进过城”限制，旧队士不永久错过；只打开或取消入城确认、测试模式入城均不计。
2. **归路的回声**：同一趟按 Q → G → J（雾 → 鼓 → 藤）顺序拜访后安全返回；其它路段不影响顺序，重复或倒序拜访这三处会重新计起。已完成章节的地点也可计数。成就一次性奖励熏肉 ×15。
3. **替无名者落款**：先收录全部九段沿途见闻，再在 J 藤之家通过任务册寻找执笔人、完成合订本落款，并安全返回。不能用本趟尚未收录的见闻提前交付。成就一次性奖励药剂 ×3。

## 存档与地图安全

- 新增 N 地标及四角房间，仅补在普通地形。原角落被旧地标占用时，找同一角落区域内最近的普通空地，不覆盖道路、旧地标、迷雾或旧主线完成状态。迁移幂等；没有可用空地时不强行覆盖。
- D/R 普通城镇通关后会变为 P 驿站：本趟刚清理的城镇仍可原地处理支线。如果旧存档已把所有对应城镇清完，则由隐将该阶段证词转送至 N 无名渡口，任务册显示替代目的地，不要求重打或恢复旧城镇。
- `game.longQuests` 仅保存安全交付的 NPC 阶段／路线、四角开关、彩蛋完成标记和入城成就条件。调查中的两份线索、当前事件、位置、机关作答和顺序路线留在内存，返程／死亡清除。
- 所有推进验证事件身份、本次地图对象、位置和步骤；击杀推进还需真实战斗胜利。重复、过期回调不能切换路线或重复推进。成就沿用现有先标记、后发奖机制。
- 远征回顾列出本次安全交付的阶段与机关数量；失败不会谎称已交付。原有主线事件仍可正常进入，不强制先做支线。

测试入口：`npm run test:long-quests` 验证双路线十阶段、真实死亡／返回路径、迁移、开关、彩蛋和一次性奖励；`npm run test:browser` 验证实际按钮、两条完整路线、正常入城与成就回顾。
