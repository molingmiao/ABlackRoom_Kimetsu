# 中后期资源平衡（2026-09-13）

## 2026-10-01：普通战快捷收取

普通战胜利后可点击“按配置收取并继续”。它始终使用已保存的“无限城配置”，不是备战页当前选中的另一个配置；只从本场未领取战利品补到目标数，按既有配置规则优先装备目标和治疗物资，保留已有额外携带，不能突破重量或挪用家中库存。不更换装备槽位。

例如配置目标为药剂 3、背包已有 1、本场掉落 4，容量足够时收取 2、其余 2 送回仓库。无相应掉落就不补该物品；满包时不拾取、剩余全送回。没有保存无限城配置时按钮不可用，可手动拾取或全部送回。

功能不自动战斗、不跳过天赋选择；精英、Boss、伏击和剧情流程不变。一次结算只处理一次，战斗中与旧回调均不能重新领取。

## 2026-10-01：生产保留库存

入口为庄园“生产情况 → 生产保留库存”。已发现且参与工人配方的材料可设置保留量，0 表示关闭。它是生产下限，不是从仓库划走一份物资：例如库存 21 份熏肉、保留 20、矿工整组需 2，则这一轮不产出；库存达到 22 后，下轮可消耗 2 并保留 20。

保护只作用于工人自动生产的负数投入。正数产出照常；多个工种按既有顺序检查当时的真实库存，不重复占用余量。缺任一原料或碰到保留线时，整组不扣料。恢复沿用原生产周期，不额外加速、不更改分工；无限城内原有的暂停庄园生产规则不变。

手动制作、交易、出征和盗窃/剧情事件不受此限制，所以保留量不是绝对库存保证。设置可高于当前库存，表示先积累储备。药剂等不被工人消耗的物品不提供无实际作用的开关。旧档缺少配置等价于全部关闭；非法存档值按 0 处理。

验证命令：`npm run test:reserves`；浏览器回归验证输入校验、取消不保存、保存不扣库存及停工原因。

## 2026-10-01：收支与获取途径

备战页的“材料获取途径”只显示已持有过的鳞片、牙齿、布料及已遭遇的野外敌人。旧存档没有历史遭遇记录，需要再次遇见后显示；不按所有图鉴内容推测玩家知道什么。无限城路线只提示已知材料，展示基础值，不含周目倍率。

完成的无限城战报按事件统计这三种材料，不用仓库前后差额冒充冒险收益。净收支为“后援回仓与宝箱入库＋实际归还背包－出发携带－城内商店花费”；未带回为出发材料与生成的奖励中未进入仓库或结算背包的部分，包括丢弃和放弃拾取。失败交易、测试模式免费采购不计花费。

当前原有规则下，死亡也归还剩余背包，所以不虚构“死亡损失”；通关/其他终局没有背包归还流程，不计尚未归还的物品收入。家中生产不纳入本账本。仅完成的摘要入档，没有可恢复的活动探索状态。旧版本战报没有此账本，不追溯估算。

手动拾取只增加背包，后援只收未拾取部分，返回时背包入库一次。修复此前手动拾取同步写入仓库导致重复收益的问题。宝箱在同一事件内只发放一次。

## 瓶颈与目标

无限城的普通、精英、Boss 掉落表原本没有鳞片和布料，但每十层补给持续使用两者。家中药剂另需 50 鳞片、30 牙齿，鬼石需 750 鳞片、300 牙齿、1500 毛皮。提高存量不会解决这个持续缺口。

本轮以战斗产出补上循环，精英/Boss 回报高于普通敌人；降低部分交易消耗作为补缺渠道，不靠增加被动生产或取消稀有资源门槛解决。

## 无限城产出

下表数量均为实际可抽取的闭区间，不含周目掉落加成。`t = min(9, floor(楼层/10))`。引擎原有战斗掉落的 `max` 不含上界，所以代码的 `max` 比表内最大值多 1；未改变全局抽取规则。

| 来源 | 鳞片 | 其他调整 |
| --- | --- | --- |
| 普通战 | 必掉 `3+t`～`6+2t` | 10 层起布料 55% 掉落 `1`～`2+floor(t/3)` |
| 精英战 | 必掉 `6+2t`～`12+3t` | 必掉牙齿 `3+t`～`6+2t`，布料 `2`～`4+floor(t/3)` |
| Boss | 必掉 `15+5t`～`25+5t` | 必掉牙齿 `8+2t`～`12+3t`，布料 `3+t`～`5+t` |
| 宝箱 | 额外必得 `5+t`～`10+2t` | 原有随机奖励池不变，不挤占稀有物品抽取 |

例如 1～9 层普通战每场 3～6 鳞片，10 层 Boss 20～30 鳞片；90～99 层普通战每场 12～24，90 层 Boss 60～70。鬼石原有战斗掉率不变。
